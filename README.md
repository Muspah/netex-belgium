# Belgian NeTEx (EPIP) Validation

This repository validates Belgian NeTEx EPIP exports.

**Beta notice:** These NeTEx and SIRI exports are very much beta. Please report all issues via this repository's [Issues](../../issues) section on GitHub.

## Data sources

- **NeTEx EPIP download:** https://data.gtfs.be/belgium/netex/schedule/netex-be-schedule.zip
- **Stop place register export (EPIP):** https://data.gtfs.be/belgium/netex/stops/spr-stopplaces.zip
- **SIRI:** can be received as XML on ZeroMQ XSUB `tcp://sub.gtfs.be:9100`. Envelopes start with `/SIRI`.

> **Note:** Use one ZeroMQ connection per consumer. To re-transmit internally, use [Universal](https://github.com/StichtingOpenGeo/universal).

## Example: connecting to ZeroMQ (Python 3)

```python
import zmq

context = zmq.Context()
socket = context.socket(zmq.SUB)
socket.connect("tcp://sub.gtfs.be:9100")

# Subscribe to SIRI envelopes
socket.setsockopt_string(zmq.SUBSCRIBE, "/SIRI")

print("Listening for SIRI messages...")

try:
    while True:
        message = socket.recv_multipart()
        print(message)
except KeyboardInterrupt:
    print("Stopping...")
finally:
    socket.close()
    context.term()
```

All services are provided best-effort.
